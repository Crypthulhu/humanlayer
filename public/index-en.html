    03The solution

    On-demand human decisions, API-native.

    HumanLayer orchestrates human decisioning exactly where it’s indispensable. A three-layer system, from the AI-prepared case to the audit-ready decision.

    Orchestration Decision Evidence
    1. LAYER 01

      Orchestration

      Detect Arbitrium and route to a qualified Sentinel. The AI agent submits a complete case with context and supporting documents; HumanLayer routes it to a qualified Sentinel based on the required criteria.

      • Evaluates the level
      • Routes the request
      • Required criteria
    2. LAYER 02

      Decision

      A qualified Sentinel issues an explicit verdict: a structured decision, with comments and justification. HumanLayer does not automate the decision; it orchestrates the intervention of an accountable human.

      • Explicit verdict
      • Justification
      • Second opinion
    3. LAYER 03

      Evidence

      A timestamped, reasoned, audit-ready decision artifact. Back to the agent: the decision is logged, auditable and ready to execute.

      • Timestamp
      • Exportable log
      • Enforceable

    Result: human authority triggered only at the right threshold.

    import hmac, hashlib, time

def verify_webhook(headers, raw_body, secret):
    # X-HumanLayer-Signature: t=1700000000,v1=<hmac>
    parts = dict(p.split("=", 1)
                 for p in headers["X-HumanLayer-Signature"].split(","))
    if abs(time.time() - int(parts["t"])) > 300:
        return False  # too old: replay
    signed = parts["t"].encode() + b"." + raw_body
    expected = hmac.new(secret.encode(), signed,
                        hashlib.sha256).hexdigest()
    return hmac.compare_digest(expected, parts["v1"])
